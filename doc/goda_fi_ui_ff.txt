INSTALL                                                *goda-fi-ui-ff-install*

The UI "ff" of goda-fi.vim (|goda_fi.txt|), which it needs:

https://github.com/Shougo/goda-fi.vim

Add it in the configuration of goda-fi.vim (|goda-fi-install|):
>go
	import "github.com/Shougo/goda-fi-ui-ff.vim/ui/ff"

	b.AddUI(ff.New())
<
==============================================================================
UI FF                                                          *goda-fi-ui-ff*

ui/ff, as ddu-ui-ff: the items in a buffer ("goda-fi-ff-{name}", filetype
"goda-fi-ff") of a split window, filtered from the command line.

The item actions go to the window the session was started from. A session
started from the window of another (from its buffer: a mapping pressed
twice, say) uses the window that one was started from instead; the
floating window of the other closes (it would cover it).

PARAMS                                                  *goda-fi-ui-ff-params*

Sizes and places are numbers or expressions of Vim, where uiParams are the
params ("(&columns - eval(uiParams.winWidth)) / 2").

split			"horizontal" (default), "vertical", "floating"
			(Neovim; Vim splits horizontally, as ddu-ui-ff),
			"tab" or "no".

splitDirection		"botright" (default), "topleft", "belowright",
			"aboveleft".

winHeight		20.

winWidth		"&columns / 2".

winRow			"&lines / 2 - 10": of a floating window.

winCol			"(&columns - eval(uiParams.winWidth)) / 2".

floatingBorder		"none": the border of the floating windows, as
			|nvim_open_win()|'s.

floatingTitle		"".

floatingTitlePos	"left".

floatingBlend		0: their 'winblend'.

autoResize		The window is no higher than its items (horizontal,
			floating), or no wider (vertical).

maxDisplayItems		1000: the lines of the buffer.

maxHighlightItems	100: the items whose highlights are drawn.

displaySourceName	"no", "short" or "long": the name of the source
			before the items. "short" leaves out what the name
			shares with the other sources at its start (file,
			fileold and filerec are [f], [fold] and [frec]), or
			keeps it and one letter more when that is shorter
			(rg and register are [rg] and [re]); a name that
			shares nothing is its first letter.

displayTree		The items of trees indented by their level, after
			"+ " (collapsed), "- " (expanded) or "  ".

reversed		The first item at the bottom.

ignoreEmpty		No window without items.

cursorPos		The line of the cursor when it opens.

highlights		Groups: "selected" (Statement), "floating"
			(NormalFloat), "floatingBorder" (FloatBorder),
			"floatingCursorLine" (CursorLine).

overwriteStatusline	v:true: the name, the counts, the input.

autoAction		{name, params, delay (100)}: the UI action run when
			the cursor is on another item ({"name": "preview"}),
			once enabled by startAutoAction or toggleAutoAction.

startAutoAction		Enable autoAction when the window opens.

previewSplit		"horizontal" (default), "vertical" or "no".

previewHeight		10.

previewWidth		80.

previewMaxSize		1000000: larger files are not previewed.

previewFloating		The preview in a floating window (Neovim) or a popup
			(Vim), beside the window of the items.

previewFloatingBorder	"none".

previewFloatingTitle	"".

previewFloatingTitlePos	"left".

previewFloatingZindex	100.

previewRow		0: where the floating preview goes, when not 0.

previewCol		0.

onPreview		"": a Vim function called after a preview with
			{previewWinId, lineNr} (ddu-ui-ff's onPreview, as the
			name of a function):
>vim
			function! MyOnPreview(args) abort
			  call win_execute(a:args.previewWinId, 'normal! zt')
			endfunction
<
Params a configuration of ddu-ui-ff has that are not here are errors
(filterSplitDirection, updateTime...): leave them out.

ACTIONS                                                *goda-fi-ui-ff-actions*

itemAction		Runs params.name (the default action when unset) with
			params.params on the items selected, or under the
			cursor.

toggleSelectItem	Selects the item under the cursor, or not.

toggleAllItems		Selects all, or none.

clearSelectAllItems	Selects none.

cursorNext		Moves the cursor down params.count (1) lines;
			params.loop goes around.

cursorPrevious		The same, up.

openFilterWindow	Types the filter in the command line; params.prompt.

toggleAutoAction	Enables autoAction, or disables it (and closes the
			preview).

preview			Shows the item under the cursor in the preview
			window (params.toggle: closes it when it shows that
			item).

redraw			Gathers again; {method: "uiRedraw"} draws again.

expandItem		Expands the tree under the cursor (a directory of
			the source file): its items go under it. Params:
			mode ("toggle": collapses it when it is expanded),
			maxLevel (the levels under it expanded too, but the
			hidden ones; -1: all), isInTree (the cursor goes to
			its first item), isGrouped (a tree that is the only
			item of its parent goes in its line, "a/b/c/").

collapseItem		Collapses the tree under the cursor, or the one it
			is in; the cursor goes to it.

togglePreview		preview with params.toggle (the params of the kind,
			imageExts say, go on).

updateOptions		Merges params into the options of the session (as
			ddu.vim's); the action redraw gathers or draws with
			them. With uiParams split: the window opens again.

checkItems		Gathers again when the files changed (the directories
			of the source file and of the trees expanded), the
			items shown until the new ones come.

chooseAction		A session of the item actions of the items, pushed
			on this one (in ff): the one chosen runs on them,
			back in this session.

inputAction		Asks for the name of an item action (input(), with
			completion) and runs it.

quit			Closes the window.
